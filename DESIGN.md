# Design

Just the words. One 36rem column, the system serif (Charter where available), no webfonts, no JavaScript. Everything is generated by `convert.py`; all styles are in `css/style.css`.

## Colour

Text on a plain ground, one accent, and a hairline rule. Light and dark follow the reader's system setting. All values are the custom properties at the top of `css/style.css`; change them there and nowhere else.

## Type

Body is 19px at 1.6 line height. Page titles run to 3rem with tight tracking; everything else stays close to body size. Dates and metadata are small, muted, and use tabular numerals. Monospace only for code.

## Motion

Small, once, and all inside `prefers-reduced-motion: no-preference`:

- Pages cross-fade, and a post's title glides from the list into its heading (view transitions; each title has a `view-transition-name` of `p-<slug>`).
- Content blocks with the `rise` class settle in on load.
- Link underlines drop slightly and take the accent on hover; list titles nudge right.
- On every page, a pencil stick figure walks along the bottom of the window to a flag as you scroll (CSS scroll timeline; hidden where unsupported).

## Adding a post

Add `content/posts/YYYY-MM-DD-slug.md` with `title` and `description`, then run `python convert.py`.
